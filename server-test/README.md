# MongoDB connection check

Install dependencies with `npm install` in this directory.
Copy `.env.example` to `.env` and set `MONGO_URI` to your connection string.
With Node.js 20.6 or later, run `node --env-file=.env index.js`.
Alternatively, set `MONGO_URI` in your shell and run `node index.js`.

Keep `.env` private; it is excluded from Git.
